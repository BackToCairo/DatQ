## 二、核心模块设计

### 2.1 NL2SQL 引擎模块

#### 2.1.1 内部架构（6阶段流水线）

```
用户输入 → Phase 1: 意图识别与预处理
           - 意图分类: query/analyze/chitchat
           - 实体抽取: 指标、维度、时间、条件
           - 歧义检测: 是否需澄清
           ↓
           Phase 2: Schema Linking
           - RAG检索DDL/文档/SQL示例
           - 语义层匹配(指标→物理字段)
           ↓
           Phase 3: Prompt构建
           - System Prompt + Schema + 业务文档
           - Few-shot示例 + 对话历史 + 用户问题
           ↓
           Phase 4: SQL生成
           - LLM调用(流式SSE) + 提取SQL代码块
           ↓
           Phase 5: SQL校验与修正
           - 语法校验 + 安全审计 + 权限注入
           - 自动修正 + 语义翻译
           ↓
           Phase 6: SQL执行与结果处理
           - 执行 + 截断 + 格式化 + 自动选图
```

#### 2.1.2 关键类设计

```python
class NL2SQLEngine:
    """NL2SQL核心引擎"""
    def __init__(self, llm_adapter, rag_service, schema_linker,
                 sql_validator, sql_executor):
        self.llm_adapter = llm_adapter
        self.rag_service = rag_service
        self.schema_linker = schema_linker
        self.sql_validator = sql_validator
        self.sql_executor = sql_executor
        self.intent_classifier = IntentClassifier()
        self.prompt_builder = PromptBuilder()

    async def query(self, user_input: str, conversation_id: str,
                    user_id: str) -> QueryResult:
        # Phase 1: 意图识别
        intent = await self.intent_classifier.classify(user_input)
        if intent.type == "chitchat":
            return QueryResult(type="chat",
                content=await self._handle_chat(user_input))
        if intent.type == "ambiguous":
            return QueryResult(type="clarification",
                questions=intent.clarification_questions)
        # Phase 2: Schema Linking
        schema_ctx = await self.schema_linker.link(intent.entities, user_id)
        rag_ctx = await self.rag_service.retrieve(user_input, top_k=5)
        # Phase 3: Prompt构建
        history = await self._get_conversation_context(conversation_id)
        prompt = self.prompt_builder.build(
            user_query=user_input, schema=schema_ctx,
            business_docs=rag_ctx.documents,
            sql_examples=rag_ctx.sql_examples,
            conversation_history=history)
        # Phase 4: SQL生成
        raw_sql = await self.llm_adapter.generate(prompt)
        # Phase 5: 校验修正
        validated_sql = await self.sql_validator.validate_and_fix(
            raw_sql, user_id, schema_ctx)
        # Phase 6: 执行
        result = await self.sql_executor.execute(
            validated_sql, schema_ctx.datasource_id)
        chart_config = self._auto_select_chart(result, intent)
        return QueryResult(type="data", sql=validated_sql,
            data=result.rows, columns=result.columns,
            chart=chart_config,
            metadata={"execution_time": result.elapsed,
                      "row_count": len(result.rows)})
```

```python
class SchemaLinker:
    """自然语言实体 → 数据库Schema映射"""
    async def link(self, entities: List[Entity], user_id: str):
        accessible_ds = await self.perm_svc.get_accessible_datasources(user_id)
        matched_tables, matched_columns = set(), set()
        for entity in entities:
            tables, cols = await self._match_entity(entity, accessible_ds)
            matched_tables.update(tables)
            matched_columns.update(cols)
        related = await self._expand_related_tables(matched_tables)
        return SchemaContext(
            tables=await self._build_table_schemas(matched_tables | related),
            columns=await self._build_column_schemas(matched_columns),
            datasource_id=self._determine_datasource(matched_tables))
```

```python
class SQLValidator:
    """SQL校验与自动修正"""
    async def validate_and_fix(self, sql: str, user_id: str,
                                schema: SchemaContext) -> str:
        if not self._is_select_only(sql):
            raise SecurityError("仅允许查询语句")
        parsed = self._parse_sql(sql)
        parsed = await self._check_and_fix_references(parsed, schema)
        parsed = await self._inject_row_permissions(parsed, user_id)
        parsed = self._remove_blacklist_columns(parsed, user_id)
        if not parsed.has_limit:
            parsed.add_limit(1000)
        if parsed.join_count > 5:
            raise ComplexityError("查询过于复杂(最多5表关联)")
        return parsed.to_sql()
```

```python
class RAGService:
    async def retrieve(self, query: str, top_k: int = 5) -> RAGContext:
        query_emb = await self.embedding_model.encode(query)
        ddl_res, doc_res, sql_res = await asyncio.gather(
            self._retrieve_ddl(query_emb, top_k=3),
            self._retrieve_docs(query_emb, top_k=5),
            self._retrieve_sql_examples(query_emb, top_k=3))
        all_results = ddl_res + doc_res + sql_res
        reranked = await self._rerank(query, all_results)
        filtered = [r for r in reranked if r.score > 0.7]
        return RAGContext(
            ddl_schemas=[r for r in filtered if r.type == "ddl"],
            documents=[r for r in filtered if r.type == "document"],
            sql_examples=[r for r in filtered if r.type == "sql_example"])
```

#### 2.2.3 Function RAG

预定义高频SQL模板，LLM只选模板+参数，提升准确率和安全性：

```python
class FunctionRAG:
    TEMPLATES = {
        "sales_by_dimension": "SELECT {dimension}, SUM(sales_amount)...",
        "trend_analysis": "SELECT DATE_TRUNC('{granularity}', ...) ...",
        "top_n_ranking": "SELECT {entity}, SUM({metric})... LIMIT {n}",
        "yoy_comparison": "SELECT ... 同比计算 ...",
    }
    async def match_template(self, query: str) -> Optional[TemplateMatch]:
        best = await self._semantic_match(query, self.TEMPLATES.keys())
        if best.score > 0.85:
            params = await self._extract_params(query, best.template_id)
            return TemplateMatch(template_id=best.template_id,
                params=params, confidence=best.score)
        return None
```

```python
class ConversationManager:
    MAX_TURNS = 20
    MAX_TOKENS = 8000
    COMPRESS_THRESHOLD = 6000

    async def get_context(self, conversation_id: str):
        messages = await self._get_messages(conversation_id, limit=20)
        total_tokens = sum(self._count_tokens(m.content) for m in messages)
        if total_tokens > self.MAX_TOKENS:
            messages = await self._compress_context(messages)
        return ConversationContext(messages=messages)

    async def _compress_context(self, messages):
        recent = messages[-10:]  # 保留最近5轮
        early = messages[:-10]
        if early:
            summary = await self.llm.summarize(early)
            return [Message(role="system",
                content=f"[历史摘要] {summary}")] + recent
        return recent
```

```python
class SemanticTranslator:
    async def translate(self, logical_sql: str, model: SemanticModel) -> str:
        parsed = self._parse_logical_sql(logical_sql)
        for ref in parsed.metric_references:
            metric = model.get_metric(ref.name)
            parsed.replace_metric(ref, metric.expression)
        for ref in parsed.table_references:
            parsed.replace_table(ref, model.get_physical_table(ref.name))
        for join in parsed.required_joins:
            parsed.add_join(join)
        return parsed.to_sql()
```

```python
class ChartSelector:
    def select_chart(self, result: QueryResult, intent: Intent) -> ChartConfig:
        num_cols = [c for c in result.columns if c.is_numeric]
        cat_cols = [c for c in result.columns if c.is_categorical]
        time_cols = [c for c in result.columns if c.is_temporal]
        if intent.analysis_type == "trend":
            return ChartConfig(type="line", x=time_cols[0], y=num_cols)
        if intent.analysis_type == "comparison":
            t = "bar" if len(result.data) <= 8 else "bar_horizontal"
            return ChartConfig(type=t, x=cat_cols[0], y=num_cols[:1])
        if intent.analysis_type == "proportion":
            return ChartConfig(type="pie", label=cat_cols[0], value=num_cols[0])
        if len(num_cols) >= 2:
            return ChartConfig(type="scatter", x=num_cols[0], y=num_cols[1])
        return ChartConfig(type="table")
```

```python
class SQLAuditEngine:
    RULES = [
        ReadOnlyRule(),           # 拦截非SELECT
        NoDropTableRule(),        # 拦截DROP TABLE
        MaxJoinTablesRule(5),     # 最多5表JOIN
        MaxSubqueryDepthRule(3),  # 最多3层子查询
        RequireLimitRule(1000),   # 必须含LIMIT
        MaxQueryTimeRule(30),     # 超时30秒
        FullTableScanWarnRule(),  # 全表扫描警告
    ]
    def audit(self, parsed_sql: ParsedSQL) -> AuditResult:
        violations = [r for r in (rule.check(parsed_sql) for rule in self.RULES) if r.violated]
        blocked = any(v.severity == "BLOCK" for v in violations)
        return AuditResult(passed=not blocked, violations=violations)
```

## 四、API 接口设计

### 4.1 RESTful API 规范

**基础路径**: `/api/v1`

**URL命名规则**:
- 资源名小写复数: `/users`, `/conversations`, `/datasources`
- 嵌套资源: `/conversations/{id}/messages`
- 操作动词: `/datasources/{id}/test-connection`

**统一响应格式**:
```json
{ "code": 0, "message": "success", "data": { ... }, "timestamp": "2026-09-04T10:00:00Z" }
```

**统一错误码**:

| 错误码 | 说明 | 错误码 | 说明 |
|--------|------|--------|------|
| 0 | 成功 | 30002 | SQL执行失败 |
| 10001 | 参数校验失败 | 30003 | SQL执行超时 |
| 10002 | 资源不存在 | 30004 | SQL安全拦截 |
| 10003 | 资源已存在 | 30005 | LLM服务不可用 |
| 20001 | 未认证 | 40001 | 数据源连接失败 |
| 20002 | 权限不足 | 50001 | 系统内部错误 |
| 20003 | Token过期 | 30001 | NL2SQL生成失败 |

## 八、安全设计

### 8.1 认证方案

```
认证流程: JWT + OAuth2.0

1. 用户登录 → 验证用户名密码
2. 签发 Access Token (JWT, 有效期2小时) + Refresh Token (有效期7天)
3. 请求携带 Access Token → API Gateway 验证签名和有效期
4. Token过期 → 前端用 Refresh Token 刷新
5. Refresh Token过期 → 重新登录

JWT Payload:
{
    "sub": "user_id",
    "roles": ["admin", "analyst"],
    "exp": 1725436800,
    "iat": 1725429600
}

可选扩展:
- LDAP/AD集成: 通过 ldap3 库对接企业目录
- SSO: OAuth2.0 Authorization Code Flow
- 多因素认证(MFA): TOTP (pyotp)
```

### 8.2 数据加密方案

| 层面 | 方案 | 说明 |
|------|------|------|
| **传输层** | TLS 1.2+ | Nginx配置SSL证书，HTTPS强制 |
| **密码存储** | bcrypt | 密码哈希存储，不可逆 |
| **数据库密码** | AES-256-GCM | 数据源连接密码加密存储 |
| **敏感字段** | 应用层加密 | 对身份证号、手机号等加密 |
| **备份加密** | AES-256 | 数据库备份文件加密 |

### 8.3 SQL注入防护机制

```
多层防护:

1. NL2SQL层: LLM生成的SQL经过语法解析器(sqlparse/sqlglot)
2. 审计层: SQLAuditEngine 规则引擎检查
   - 只允许 SELECT
   - 拦截 UNION/INSERT/UPDATE/DELETE/DROP/ALTER/TRUNCATE
   - 拦截危险函数(xp_cmdshell, LOAD_FILE等)
3. 执行层: 使用参数化查询，禁止字符串拼接SQL
4. 权限层: 数据库连接使用只读账号
5. 网络层: 数据库不暴露公网端口
```

### 8.4 数据脱敏规则引擎

```python
class DataMaskingEngine:
    """数据脱敏引擎"""
    RULES = {
        "phone": lambda x: x[:3] + "****" + x[7:],       # 138****1234
        "id_card": lambda x: x[:6] + "********" + x[14:], # 110101********1234
        "email": lambda x: x.split("@")[0][:2] + "***@" + x.split("@")[1],
        "bank_card": lambda x: "**** **** **** " + x[-4:],
        "name": lambda x: x[0] + "*" * (len(x) - 1),     # 张*
        "amount": lambda x: "***",                         # 金额隐藏
    }

    def mask(self, data: List[Dict], columns: List[Column], user_id: str) -> List[Dict]:
        # 根据用户权限判断是否需要脱敏
        masking_rules = self._get_masking_rules(user_id, columns)
        for row in data:
            for col, rule in masking_rules.items():
                if row.get(col):
                    row[col] = self.RULES[rule](str(row[col]))
        return data
```
